# GRIP Bomb Timer Auto — GitHub Actions build
Проект включает автоматическую сборку debug APK через GitHub Actions. Сборка не проверена на GitHub в этой сессии.

## После загрузки файлов в репозиторий
1. Откройте вкладку **Actions** → **Build Android APK** → **Run workflow**.
2. Дождитесь завершения (зелёная отметка).
3. Откройте выполненную сборку, в разделе **Artifacts** скачайте `GRIP-Bomb-Timer-Auto-APK` (ZIP).
4. Распакуйте ZIP на телефоне и установите `app-debug.apk`.

Важно: нужно загрузить **содержимое распакованного архива**, сохранив структуру папок, включая `.github/workflows/build.yml`. Простая загрузка ZIP как одного файла в репозиторий сборку не запустит.

## Функции и ограничения
- Захват экрана с явным системным разрешением Android; root не нужен.
- OCR области X 858..1483, Y 727..803 относительно 2340x1080.
- Автозапуск при распознавании текста установки бомбы; ручной резервный START/RESET.
- OCR Latin ML Kit: русский текст может не распознаваться; тестирование в игре не проводилось.
- Автоматическое обнаружение обезвреживания не реализовано.
- 40 секунд — редактируемое значение по умолчанию.
- Проверьте правила игры перед использованием.
